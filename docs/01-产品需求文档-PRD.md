# 开蒙纸坊 · 产品需求文档（PRD）

> 版本 v0.16 · 2026-09-27 · 状态：草稿
>
> 优先级说明：P0 = MVP 必须；P1 = V1 目标；P2 = V2 及以后。

---

## 1. 背景与目标

### 1.1 产品一句话

面向家长、幼小教师和书法国学机构的蒙学印刷工坊：把经典内容和可定制的纸张模板结合，一键生成可打印的练习纸、字帖、诗词卡和线装小册。

### 1.2 要解决的问题

现有工具各管一段，用户要在几个产品之间来回搬运：

- 字帖生成器只认「输入文字」，没有内容库，模板固定，做完就丢，不能保存、不能成册。
- 诗词类 App 内容丰富、设计精美，但只能看和分享图片，不能变成练习纸。
- 通用设计工具能做版式，但不懂田字格、竖排、注音、描红这些规则。
- 家长和老师最终要的是一叠能直接打印、尺寸准确、内容可靠的纸。

### 1.3 产品目标（第一年）

- 北极星指标：每周成功导出或打印的页数。
- 辅助指标：内容库到导出的转化率、用户保存的模板数、周留存、成册导出数。
- 定性目标：用户提到本产品时的第一印象是「内容靠谱、纸好看、打出来尺寸准」。

### 1.4 非目标（明确不做）

- 不做在线手写、手写识别、书写评分。
- 不做诗词阅读社区或内容创作社区。
- 不做通用海报或平面设计工具。
- 不做题库类练习（口算、阅读理解等）。

## 2. 用户与场景

### 2.1 目标用户

| 用户 | 特征 | 核心诉求 |
| --- | --- | --- |
| 家长 | 孩子 3 到 10 岁，家中有打印机或愿意去打印店 | 快速拿到一张「今天练这个」的纸，带描红，低年级带拼音，写上孩子名字 |
| 幼儿园与小学教师 | 按学期、按单元备课，需要整班用量 | 按年级选内容，批量生成整本练习册，统一版式，有封面和目录 |
| 书法与国学机构 | 有品牌意识，注重古风与专业感 | 自定义 logo 与版式，竖排、线装风格，可印成册 |
| 成人书法爱好者（次要） | 临帖、抄经 | 竖排界栏纸、抄经格、集字字帖 |

### 2.2 用户故事

- 作为家长，我想选一首《静夜思》，选一张带拼音的田字格描红纸，填上孩子名字，直接打印。
- 作为家长，我想把孩子这学期要背的二十首古诗做成一本小册子，每天一页。
- 作为老师，我想按部编版二年级上册的识字表，每个单元生成一套练习纸，全班打印。
- 作为机构老师，我想用《千字文》做一本竖排线装风格的字帖，封面印机构名字。
- 作为用户，我想把自己做好的版式存成模板，下次换一首诗直接套用。
- 作为用户，我粘贴一段自己写的儿歌，不需要拼音就直接出纸；需要拼音时系统自动注音，我改一下多音字再出纸。

### 2.3 核心链路

```
选内容（资料库 / 自定义） → 选纸张（模板 / 设计器） → 预览（分页、实际尺寸） → 导出 / 打印
```

所有功能都服务这条链路。MVP 阶段任何不在链路上的需求一律延后。

### 2.4 信息架构

顶部导航只有五项，每一项对应一种用户资产或动作：

| 导航 | 里面有什么 | 说明 |
| --- | --- | --- |
| 首页 | 今日一页、三个起点、最近用过的纸、我的文选 | 入口，不承载管理功能 |
| 资料库 | 分类、检索、作品详情、用自己的文字 | 内容从这里来 |
| 纸坊 | 按用途、排版、年龄、风格挑纸；我的模板；从空白设计 | 纸从这里来 |
| 文选 | 一组篇目的有序组合，装订成册时自动加封面与目录 | 曾用名「合集」「练习册」。文选指编选的篇目，成册是它的输出，见决策 D-009 |
| 个人中心 | 我的作品、我的模板、我的文选、导出记录、方案 | 用户的全部资产。原型说明层（标注、流程总览）不属于产品导航 |

三个核心对象要分清：

- 模板：只有版式与参数，不含内容。
- 作品：一次「内容 + 纸张 + 参数」的组合，可再打开、再打印，是用户最直观的成果。
- 文选：一组篇目的有序组合，只记内容不记纸张，装订成册时套用当前纸张设置。

## 3. 功能需求

### 3.1 资料库

#### 3.1.1 内容范围

| 分类 | 内容 | 优先级 |
| --- | --- | --- |
| 蒙学经典 | 三字经、百家姓、千字文、弟子规、声律启蒙、笠翁对韵、幼学琼林、增广贤文、朱子家训 | P0（前四种）/ P1（其余） |
| 诗词 | 小学必背古诗按年级分册、唐诗三百首、宋词精选、节气诗与咏物诗等主题集 | P0（必背古诗）/ P1（其余） |
| 古文选段 | 论语、大学、中庸、老子、孟子的短句选段，按难度标注 | P1 |
| 汉字 | 部编版各年级识字表与写字表、常用字表、部首表、笔顺规范 | P0（识字表）/ P1（其余） |
| 扩展 | 拼音、成语、对联、节日节气、名言警句 | P2 |

#### 3.1.2 数据结构

四级结构，每一级都能单独被选进纸张：

```
作品 work
 └─ 篇章 section
     └─ 句 sentence
         └─ 字 character
```

| 层级 | 字段 |
| --- | --- |
| 作品 | 标题、别名、作者、朝代、体裁、年级标签、主题标签、难度、来源与所据版本、简繁版本、许可信息 |
| 篇章 | 标题、序号、说明 |
| 句 | 原文、带声调拼音、注释、译文、断句与标点、押韵标记 |
| 字 | 本字、拼音（含声调、此句中的读音）、多音字标记、部首、笔画数、结构类型、笔顺序列、繁体对应字、异体字 |

规则：

- 简繁转换按词做，不按字做，避免「发 / 髮 / 發」类错转。
- 多音字在句级记录实际读音，字级记录全部读音。
- 每条内容记录来源版本，允许同一作品存多个版本并切换。

| 检索 | 标题、作者、首句、任意句、关键词；支持拼音首字母 | P0 |

| 粒度选择 | 选整篇、选段落、选句、选字 | P0（整篇与句）/ P1（字级） |
| 按教材单元取字 | 选年级与单元，自动列出该单元识字表与写字表 | P1 |
| 朗读音频 | 朗读音频与二维码嵌入纸张 | P2 |

#### 3.1.4 文选（篇目组合）与收藏

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 收藏 | 收藏作品、句、字 | P0 |
| 文选 | 把任意粒度的内容组成有序篇目，可命名、排序、分组，是装订成册的依据 | P1 |
| 官方文选 | 官方预置如「一年级上学期必背」「二十四节气诗」，可复制为我的文选 | P1 |
| 文选分享 | 生成链接，他人可复制到自己账户 | P2 |

#### 3.1.5 自定义内容与导入

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 手动输入 | 输入或粘贴文本，自动分句、切字。是否注音由用户选择，默认不注音，不注音时直接出纸 | P0 |
| 注音核对 | 仅在用户开启注音时出现：展示逐字拼音，多音字高亮，用户可修改读音，改后可保存为个人规则 | P0 |
| 文件导入 | txt、markdown、docx，保留标题与分段 | P1 |
| 私有与公开 | 自定义内容默认私有；申请公开需审核 | P1 |

#### 3.1.6 内容质量、版本与版权

- 内置内容每条有版本号、校对人、校对日期，修改留痕。
- 经典原文为公版；拼音标注、注释、译文自建或使用开放许可数据，每条记录许可信息。
- 核心库的拼音逐句人工校对；扩充库的拼音标「未校对」，用户开启注音时提示。
- 用户内容标明来源；公开库内容需经审核，可举报下架。

#### 3.2.2 网格系统

| 网格类型 | 说明 | 优先级 |
| --- | --- | --- |
| 田字格 | 四分格，最常用 | P0 |
| 米字格 | 加对角线 | P0 |
| 回宫格 | 内外双框 | P1 |
| 九宫格 | 三乘三分格 | P1 |
| 方格 | 无内线 | P0 |
| 横线 | 单线或双线 | P1 |
| 四线三格 | 拼音练习格 | P0 |
| 空白 | 仅边框或无框 | P0 |
| 竖排界栏 | 仿古线装书：版心、鱼尾、栏线、书口题名 | P1 |
| 抄经格 | 竖排小格，适合抄经与长文 | P2 |

网格参数：格子边长、格间距、行间距、线宽、线色、实线或虚线、行列数或按页自动填充、格内辅助线开关。

- 格子边长：最小 8 毫米；上限按当前纸张、边距、标题与落款占位、是否注音动态计算，最大即一页只放一格。滑块与数字框联动，界面上显示当前上限与行列数。
- 格间距：0 到 20 毫米，0.1 毫米步进。设为 0 时相邻格子共用边线，没有间隔。

网格块的排布规则：

- 默认按页自动填充：由纸张尺寸、边距、标题栏与落款栏的占位，以及格子边长和格间距，算出每页能放几列几行。
- 算出的整块网格在内容区内水平、垂直居中，不从左上角起排，四周留白均匀。横排、竖排、仿古界栏都遵守同一规则。
- 改格子边长、格间距、边距或纸张时，行列数与页数实时重算。
- 用户可改为指定行列数，或改对齐方式为左上对齐（P1）。

#### 3.2.3 文字排版规则

| 规则 | 说明 | 优先级 |
| --- | --- | --- |
| 书写方向 | 横排从左到右；竖排从右到左，标点正确旋转与定位 | P0（横排）/ P1（竖排） |
| 注音开关 | 注音是可选项，不是必选。默认值由模板与内容共同决定：识字表、学前与一年级内容默认开；临摹、竖排、卡片、二年级以上默认关。用户可随时切换，关闭注音的路径最短 | P0 |
| 注音位置 | 横排在字上方，竖排在字右侧；注音字体与字号独立设置 | P0 |
| 注音范围 | 全部字、只标多音字、按年级只标未学过的字 | P1 |
| 描红样式 | 浅灰实心、空心轮廓、点线、红色实心，透明度可调 | P0（浅灰与空心）/ P1（其余） |
| 练习模式 | 例字、描红、空格的组合，如「一例二描三空」；每字一行或连续排 | P0 |
| 笔顺图 | 在例字旁显示分步笔顺小图，步数按字自动生成 | P1 |
| 分句排法 | 整篇抄写时三种排法：短语不拆行（短语整体放在同一行，三字经、千字文这类等长短语自动对齐成列）、每句一行（句号、问号、叹号或原文换行处另起一行）、连续排（一字一格顺排）。默认短语不拆行。篇章间可强制分页 | P0 |
| 短语间距 | 短语之间只留一段空白，0 到 40 毫米可调，精确到 0.1 毫米，不占格子；小于格间距时按格间距。每行按可用宽度尽量多放短语，放不下的整体换行；空白行不画格。句子边界按句号、问号、叹号判断；原文换行只在该行没有标点时算句子边界，所以诗的一联会排在同一行 | P0 |
| 卡片排版 | 诗词卡片与描红纸共用格子模型：正文字号等于格子边长，字距等于格间距，网格类型可选无格、田字格、米字格等；每句一行居中，标点隐藏或挤在字格角落；默认自动适配一页（自动定格子边长），取消后按格子边长分页 | P0 |
| 装饰字字号 | 标题、作者、落款、拼音不进格子，字号按比例从格子边长派生：拼音约为格子的 0.3 倍；卡片标题为格子的 0.85 倍、限 8 到 18 毫米，描红纸标题固定 6.5 毫米；作者为标题的 0.4 倍；落款、页码 3.6 到 4.2 毫米固定不缩放。标题字号可手动覆盖，作者随之，标题块高度随字号重算 | P0 |
| 标点处理 | 只对整篇抄写生效，描红练习永远不排标点。标点从不占格子：隐藏，或以小字放在短语末字的右下角。自然满足行首禁则。分句排法依据标点与原文换行判断短语和句子边界 | P0 |

### 3.3 排版与输出

#### 3.3.1 内容流入与分页

- 内容按模板插槽流入，超出自动分页；支持「一首一页」与「连续排」两种模式。
- 篇章间可强制分页；可设置每页最多行数或格数。
- 分页结果可预览并手动调整分页点。

## 6. 技术方案

| 层 | 建议 | 理由 |
| --- | --- | --- |
| 前端 | React 或 Vue，TypeScript | 团队熟悉度优先 |
| 画布 | SVG 自研，坐标以毫米为单位 | 矢量、可精确对应打印、易转 PDF |
| PDF | 客户端 pdf-lib 加 SVG 转换；高保真走服务端 Chromium 打印 | 见决策 D-004 |
| 注音 | pinyin-pro | 支持多音字与声调 |
| 笔顺 | makemeahanzi 与 hanzi-writer 数据 | 开源，覆盖九千余字 |
| 简繁 | OpenCC | 按词转换 |
| 字体 | 霞鹜文楷、思源宋体、思源黑体；fonttools 或 opentype.js 子集化 | 可商用，控制体积 |
| 后端 | Node 或 Python，Postgres，对象存储 | 常规 |
| 检索 | 初期用 Postgres 全文检索 | 数据量小 |
| 桌面 | 后期用 Tauri 包桌面版 | 打印稳定性 |

关键技术点：

- 竖排不要依赖 CSS writing-mode，自己按字定位，标点与注音位置可控。
- 描红的空心轮廓从字体轮廓提取，浅灰描红用透明度，点线描红用虚线描边。
- 笔顺图用 hanzi-writer 的笔画数据逐步渲染为静态 SVG。
- 所有尺寸在数据层用毫米，渲染时换算像素，导出时换算 pt。

## 7. 路线图

### MVP（验证「选内容出纸」）

范围：

- 资料库：蒙学四种、小学必背古诗、部编版识字表。

- 家长从进入到打印出第一张纸不超过三分钟。
- 打印出的田字格边长误差在 0.5 毫米内。
- 内置内容零错字（人工抽检）。

- 画布式纸张设计器，模板保存与参数化。
- 竖排与线装版式，笔顺图。
- 文选与装订成册，封面目录；保存作品与个人中心。
- 登录与云同步，会员付费。

### V2（协作与生态）

- 班级与分享，团队与机构版。
- 模板市场，创作者分成。
- 繁体版本，印刷下单，书法字体与集字字帖。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 打印尺寸失真 | 用户最直接的投诉 | 全程毫米制；打印前提示关闭缩放；页角校准尺；提供「打印测试页」 |
| 字体版权 | 法律风险 | 只内置开源字体；用户上传自负；书法字体单独采购 |
| 名画扫描来源 | 版权与授权争议 | 只用明确允许自由使用的公版扫描，记录出处；博物馆限制商用的图不用 |
| 注音错误 | 影响教学 | 注音默认按内容开关，减少暴露面；核心库人工校对，扩充库标「未校对」；用户内容允许逐字改音并沉淀规则 |
| 文本版本差异 | 用户质疑 | 标注所据版本，允许切换 |
| 竖排渲染兼容 | 显示与打印不一致 | 自研定位，不依赖浏览器竖排 |
| 内容审核压力 | 运营成本 | 公开内容先审后发；早期不开放公开 |
| 需求泛化 | 变成通用设计工具 | 坚持核心链路，非目标清单 |
