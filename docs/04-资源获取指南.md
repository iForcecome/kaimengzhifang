# 开蒙纸坊 · 资源获取指南

> 版本 v0.1 · 2026-09-27 · 状态：草稿
>
> 说明资料库和纸张素材从哪里来、能不能商用、怎么取、怎么校。每类资源给出首选来源、备选来源、许可类型、取用步骤和注意事项。许可信息以各来源页面当时的说明为准，接入前逐一核对一次。

---

## 1. 原则

- 只用两类资源：公有领域，或明确允许商用的开放许可（CC0、CC BY、OFL、MIT 等）。「仅限个人使用」「非商用」的一律不进库。
- 每一条内容、每一张图、每一款字体都记录来源、许可、取用日期和取用人，见第 9 节的记录模板。
- 原文以一个权威版本为准，标注所据版本；不同版本的异文另存，不混排。
- 自动化只做底稿，进入核心库的内容必须两人校对。
- 有版权的注释、译文、赏析一律不抄，自己写或用公版旧注。

## 2. 经典原文：蒙学、诗词、古文

| 来源 | 内容 | 许可 | 用法 |
| --- | --- | --- | --- |
| [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) | 全唐诗、全宋诗、宋词、蒙学（三字经、百家姓、千字文、弟子规、声律启蒙、幼学琼林等）、论语、诗经、楚辞 | 仓库为 MIT，原文本身公版 | 作为底稿导入；注意部分为繁体存储、存在错字异文，不能直接上线 |
| [维基文库](https://zh.wikisource.org/) | 公版古籍、诗文 | 公有领域或 CC BY-SA，按页面标注 | 交叉核对底稿；抄录时保留来源页面链接 |
| [中国哲学书电子化计划 ctext.org](https://ctext.org/zhs) | 三万余部传世文献，含多版本对照 | 网页可自由查阅；批量与 API 需按其条款申请 | 核对版本与异文；不做批量抓取 |
| 纸质权威版本 | 中华书局、上海古籍等点校本 | 原文公版，点校与注释有版权 | 只取原文作为所据版本，不取注释 |

取用步骤：

1. 从 chinese-poetry 取底稿，转简体，按作品、篇章、句、字四级拆分。
2. 指定一个所据版本（如《全唐诗》卷次、王相训诂本），逐句对照修正。
3. 第二人独立校对一遍，差异处回到所据版本裁决。
4. 记录版本、校对人、日期，进核心库。

## 4. 拼音、注释、译文

| 资源 | 来源 | 许可 | 做法 |
| --- | --- | --- | --- |
| 自动注音 | [pinyin-pro](https://github.com/zh-lx/pinyin-pro) | MIT | 生成底稿，支持多音字与声调 |
| 多音字定音 | 人工 | — | 逐字过一遍，按句意定读音；「一」「不」变调按教材习惯统一规则并写进校对规范 |
| 注释、译文 | 自己写 | 自有版权 | 面向低年级，短句，每句一两条注释；找语文老师撰写并署名 |
| 公版旧注 | 清代及以前注本，如王相《三字经训诂》 | 公有领域 | 可摘引，标注出处 |
| 不可用 | 古诗文网、搜韵等站点的注释译文 | 有版权 | 只作参考，不抄录 |

## 8. 朗读音频（P2）

- 自录：找播音或语文老师录制，签授权，成本可控，质量最稳。
- 合成：商用 TTS 服务，确认其许可允许生成内容商用并可离线分发。
- 不用：网络上他人上传的朗读音频。

## 10. 内容流水线

```
源文件 → content/raw/           原样保存底稿与来源
       → content/works/*.json   四级结构：作品、篇章、句、字
       → 自动注音（pinyin-pro）
       → 人工校对（两人）        改音、纠错、定版本
       → 版本号与来源记录
       → 发布到资料库
```

- 用 git 管理 `content/`，校对以合并请求形式进行，评论留痕。
- 自动检查：字是否在《通用规范汉字表》内、拼音是否合法音节、每句字数与拼音数是否一致。
