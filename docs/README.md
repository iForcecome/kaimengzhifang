## 维护约定

- 每次改动 PRD 请更新文件头部的版本号与日期，并在文末「变更记录」补一行。
- 功能优先级使用 P0 / P1 / P2：P0 为 MVP 必须，P1 为 V1 目标，P2 为 V2 及以后。
- 参考产品文档中的链接采集于 2026-09-25，链接失效请直接修正或删除。
- 决策一旦拍板，把「待定」改为「已定」并写明理由，不要删除历史。
