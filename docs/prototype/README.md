# 交互原型

`index.html` 是开蒙纸坊的可点击原型，单文件，双击即可在浏览器打开，无需构建。

在线版本（同一份文件）：https://claude.ai/artifact/TijzKCnnNN995TRFNaLPkp

## 怎么看

- 右下角「原型说明」打开说明层：每页的目的、标注对照、主要交互、状态与边界、对应 PRD 章节。默认收起，不干扰产品界面。
- 说明层里的「标注」在页面上显示红色编号，与条目一一对应，点条目会滚动到对应位置。
- 说明层里的「查看流程总览」是全部页面的地图，蓝底四格为核心链路。

## 覆盖的页面

首页、资料库、作品详情、用自己的文字、纸坊、出纸工作台、打印预览、文选、个人中心（我的作品、模板、文选、导出记录、方案）。

## 原型里真实实现的部分

- 排版引擎以毫米为单位生成 SVG，田字格、米字格、回宫格、九宫格、方格、四线三格、竖排界栏都是真实绘制。
- 每页的行列数按纸张、边距、格子边长和格间距自动算出，整块网格在内容区内水平、垂直居中。
- 画底：四幅公版名画扫描（千里江山图、富春山居图、溪山行旅图、早春图，见 bg/README.md）加宣纸纹理、如意云纹，位置（整页、页眉页脚、四边）与浓淡可调。
- 描红练习、整篇描红、诗词卡片、空白纸四种模式，横排与竖排，分页按纸张与格子大小实时计算。
- 内容选取支持整篇、选句、选字。
- 注音是可选项：识字表、学前与一年级内容默认开，其余默认关；可切换为只标多音字。自定义文本默认不注音直接出纸，开启「需要拼音」后才自动注音并高亮多音字让你核对。
- 文选是篇目组合，装订成册含封面、目录、正文、译文页与全局页码。
- 作品是纸张加内容的组合，在工作台「保存作品」，个人中心可再打开、再打印。
- 纸坊按用途、排版、适合年龄、风格筛选，卡片标出规格与注音默认值。
- 模板、作品、导出记录存在浏览器本地。

## 原型里只做模拟的部分

- 导出 PDF 显示分步进度并记入导出记录，打印打开产品自己的打印对话框，两者都不产生真实文件。
- 登录是微信扫码示意，不会真正登录。
- 注音只内置演示字表，正式版接 pinyin-pro。
- 登录、云同步、班级、模板市场、印刷下单只有入口。
- 「实际尺寸」需先用「校准屏幕」对比银行卡保存比例，比例存在浏览器本地。

## 修改

直接改 `index.html`。文件结构从上到下依次是：样式、页面结构、内容数据与页面说明（`WORKS`、`TEMPLATES`、`NOTES`）、排版引擎（`buildPages` 等）、交互逻辑。
